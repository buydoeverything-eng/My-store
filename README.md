# BUYDO 🛍️

### Buy everything with a Buydo

BUYDO is a modern, responsive e-commerce landing page designed for trendy clothing, apparel, and lifestyle products.

## ✨ Features

- 🛒 Functional shopping cart
- 🔢 Live cart item count
- ➕ Add products to cart
- ➖ Increase/decrease product quantity
- ❌ Remove products from cart
- 💰 Automatic total price calculation in INR
- 💾 Cart data saved using Local Storage
- 📱 Fully responsive mobile design
- 🎨 Modern minimalist UI
- 🔍 Product grid with clothing and lifestyle products
- 📧 Newsletter signup
- 🛍️ Slide-out shopping cart
- ⚡ Smooth scrolling and transitions

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Alpine.js
- JavaScript
- Unsplash Images
- Local Storage
